## 03-c2: A trial should verify the produced artifact independently instead of treating an agent’s completion status as proof. Stack Overflow’s author argues that an exit code can reflect the agent’s self-assessment, and recommends checking outcomes; Cloudflare describes a system design that validates citations and leaves decisions with analysts. These are a practitioner warning and a vendor implementation account, not a controlled comparison of verification methods.
- stackoverflow — [A green exit code is not evidence that the work happened](https://stackoverflow.blog/2026/10/08/a-green-exit-code-is-not-evidence-that-the-work-happened/); The status is a self-assessment, and you have plugged it into a socket built for an observation.

## 03-c4: Measure cost per verified task together with latency, rather than tracking usage alone. Stack Overflow recommends decision-level cost and latency signals, while LegalOn’s account describes setting budgets and says a feature-level customer-value metric was still being built. This supports including budget and outcome measures in a reversible trial; it does not establish that the reported cost reduction preserved value for other teams.
- stackoverflow — [Part 5: Operating an LLM system: observability, cost, routing, and the platform underneath](https://stackoverflow.blog/2026/10/08/part-5-operating-an-llm-system-observability-cost-routing-and-the-platform-underneath/); quality (shadow-eval ≥ baseline − 2%, rolling 7d), latency (p95 excluding human time under your interaction budget), and cost (USD per 1k decisions within ±20% of plan).

## 03-c5: For any trial that runs agents in hosted or temporary environments, include an access and persistence check: establish which tools and repository permissions are available, where required state survives restarts, and what spending limit or stop condition applies. The podcast guest describes ephemeral environments, sandboxed agents, and an MCP gateway that controls tool access; Simon Willison’s account shows that a new API key was needed for one private-repository import. These examples inform checks to run, not findings that a particular deployment is unsafe or over budget.
