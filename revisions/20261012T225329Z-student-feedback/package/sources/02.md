## 02-c3: GitHub describes ReviewBench as a versioned code-review benchmark and reports that offline changes evaluated before A/B tests consistently pointed in the same direction as later production results. This is a potentially useful evaluation signal for code review, but the cited account reports the publisher's own validation and experiments rather than independent confirmation.
- microsoft-github — [ReviewBench: An open benchmark for AI code review](https://github.blog/ai-and-ml/github-copilot/reviewbench-an-open-benchmark-for-ai-code-review/); We version the benchmark dataset, judge, and matcher used in every evaluation
